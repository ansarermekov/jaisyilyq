# JAISYILYQ — сайт новогодних боксов и игрушек

Статический сайт: вся логика и все изображения находятся в `index.html`.
Сборка не нужна. Библиотеки (React, Tailwind, шрифты Google) подключаются по интернету через CDN.

## Netlify
1. Откройте https://app.netlify.com/drop
2. Перетащите на страницу распакованную папку проекта (или весь ZIP, распакованный).
3. Сайт сразу получит адрес вида *.netlify.app.

## GitHub Pages
1. Создайте репозиторий и загрузите все файлы из папки в корень.
2. Settings → Pages → Source: «Deploy from a branch», ветка main, папка / (root).

## Как редактировать
Откройте `index.html` в текстовом редакторе:
- `BOXES` — 7 подарочных боксов (названия, описания, состав, цены, поле `image`).
- `TOYS` — 5 новогодних игрушек.
- `IMG` — фотографии игрушек (встроены в код).
- `WA` и `IG` — номер WhatsApp и ссылка Instagram.
